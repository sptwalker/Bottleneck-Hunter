# OpenAPI 产品概述

## 产品体系介绍

OpenAPI 聚焦多元化数据服务需求，依托稳定、高效的接口能力，为用户提供四大核心类型数据服务，覆盖**人工智能服务**、**投研资讯服务**、**金融数据服务**及**私域数据服务**，助力用户高效获取数据、提升业务效率。具体介绍如下：

### 一、人工智能服务
满足用户深层次的知识检索与智能交互需求，提供以下核心能力：
* **知识库查询**：支持快速检索结构化知识库，精准获取文本切片信息。
* **知识库溯源**：支持从检索结果快速定位并下载原始文档，确保信息可靠性。
* **投研线索**：利用 AI 深度挖掘市场动态，提取高价值投研线索。
* **AI 对话与 Agent**：支持接口调用**Gangtise AI问答**和**Gangtise Agent**包括**一页通**、**同业对比**、**主题跟踪**、**调研提纲**、**投资逻辑**和**业绩点评**等。

### 二、投研资讯服务
专为专业投研场景打造，整合全维度市场信息，覆盖投研工作全流程：
* **纪要查询下载**：涵盖会议纪要、投资者关系活动记录及三方平台纪要的查询与原文下载。
* **首席观点**：实时汇集并查询各大券商首席分析师的核心观点与深度解读。
* **投研日程**：提供结构化的市场路演、调研及策略会日程数据。
* **研报查询下载**：支持市场内外资研报原文的精准查询与快速下载。
* **公司公告查询下载**：支持 A 股上市公司公告的实时检索与文档下载。

### 三、金融数据服务
依托深厚的数据底座，提供高精度的市场行情与基础财务数据支持：
* **行情数据**：提供 A 股及港股的日 K 线、分钟 K 线等行情查询。
* **财务报表**：支持财务三大报表（资产负债表、利润表、现金流量表）的累计值数据调取。
* **深度分析**：涵盖上市公司的主营构成分析、估值分析等量化数据服务。

### 四、私域数据服务
助力企业实现私域资产的 AI 化管理与安全调用：
* **AI 云盘查询**：支持对个人或企业云盘中的文档、音视频等资源进行结构化检索。
* **AI 云盘文件下载**：提供稳定安全的接口，支持云盘内各类文件的自动化下载与管理。

## 开发流程说明

1. 登录 gangtise 开放平台，登录后申请开发账号与接口权限。
2. 审批后，获取 Access Key 和 Secret Key。
3. 通过调用获取开发账号 <a href="#/markdown/access-token">【accessToken】</a>接口，获取 accessToken。
4. 调用相关接口，请求的 header 设置 Authorization 属性值为 `{accessToken}`。

> 注：accessToken 样例：`Bearer 61e5c0ce-c026-4ecd-94ef-34c753aaf2f2`
