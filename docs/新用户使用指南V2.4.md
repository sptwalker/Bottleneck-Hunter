## 1\. 首次登录与账户

### 1\.1 普通用户注册

在登录页可注册新用户，流程通常为：

1. 填写用户名/邮箱/密码，可能需要**邀请码**（由管理员在「用户管理中心 → 邀请码」生成）；

2. 系统发送**邮箱验证码**

3. 从邮箱获取并输入验证码完成注册。

### 1\.2 账户设置

右上角头像 → 账户设置：改显示名、邮箱、密码。旁边的按钮可退出登录。

## 2\. 首次配置向导：系统配置中心（必做）

登录后**第一件事**：进入顶栏 **系统配置中心**，把模型配好，否则分析会提示「无可用 LLM」。

系统配置中心分几块：

### 2\.1 API Key 管理（Provider 统一管理）

- 在这里三步完成新手的系统AI模型配置：

- **第一步**，配置AI API KEY，请配置至少3个LLM API（系统需要多AI角色）

- 每个服务商（OpenAI/DeepSeek/…）一张卡片，可编辑 **API Key、默认模型、Base URL**；内置服务商与自定义端点同等可编辑。

- 编辑态有「测试」按钮，可**不保存**直接测当前填的配置是否连得通。

- 这里保存的模型配置是全系统模型的**单一真源**——各处的模型下拉都从这里动态生成。

- **第二步**：用户选择自己的模型使用策略，如果用户配置了多个模型，需要告诉系统优先使用付费还是免费的模型，优先使用质量高还是低价的模型，这个选择决定了未来系统自动使用模型的策略

- **第三步**：最后点击“模型自动测试并配置”按钮，系统将自动测试用户提供的所有模型API接口，并自动完成模型的配置工作。测试并自动配置完成后，AI模型的配置就完成了。

### 2\.2 模型自定义分配（给高阶用户使用）

这个部分是提供给高阶用户使用，普通用户使用自动配置即可。

系统把 LLM 使用点划成 3 个模块页签：

- **产业链分析**（拆解 / 供应商评估 / 交叉验证 / 圆桌…）

- **观察池**（催化剂 / 策略引擎 / 论点追踪 / 交易复盘 / 参数调优 / 深度分析…）

- **决策中心**（L1 宏观 / L2 组合 / L3 战术 / L4 执行 \+ 投委会各委员）

每个角色给它挑一个服务商 \+ 模型。**多模型角色**（右侧「多模型」标记）可配多个：

- 例如 **L1 宏观策略** 有两个槽：**宏观市场分析师 / 产业动向分析师**（用于宏观咨询的两位分析师，也是宏观策略的双模型交叉验证来源）；

- **瓶颈分析** 最多 3 个模型做交叉打分。

不配的角色会走智能调度自动兜底（见 2.3）。手动填了就以你的为准（覆盖），留空即交给系统自动选型。

### 2\.3 自动测试的原理 & 调度看板

- **综合测试**：点 2.1 的「模型自动测试并配置」后，系统批量测各服务商各模型的连通性/各项能力（连通性 / JSON / 中文分析 / 速度 / 评分力 / 指令遵循 6 维度）。

- **智能调度自动选型**：测试结果作为「质量信号」喂给内置的智能调度器，系统按 **运行时健康度 + 成功率 + 能力分 + 你的策略偏好** 为每个角色**动态选模**，某个模型失效/超额会**无缝切换**到下一个，无需你手动指定，也无需"采纳推荐"。

- **🧭 调度看板**（配置中心页签）：可查看「当前各角色实际选型」（标注是自动还是你手填覆盖）、各模型近期用量与健康度。

> ✅ 最小可用：在 API Key 管理里配好**至少一个**服务商的 Key + 默认模型，点一次「模型自动测试并配置」即可开始用——所有角色由调度器自动兜底，无需手动分配。

### 2\.4 配置外部数据源

- 配置外部数据源后，系统数据的准确性和可靠性将大大提升

- 目前系统推荐的数据源均有免费数据额度，用户可以自行免费注册账号并获取API KEY填入

- **Gangtise（境内一手官方源，最高优先）**：开启后，美股/A股的**日K线与实时报价**优先走这一层，并额外为系统提供**官方宏观指标、财报日历（催化剂）、券商研报证据、主营构成、股东结构、估值分位**等投研数据（A股覆盖最全）。凭据由管理员在配置中心统一开关。

- 目前推荐数据源包括

    - Financial Modeling Prep：https://site.financialmodelingprep.com

    - Finnhub：https://finnhub.io

    - Tushare Pro：https://tushare.pro

    - Alpha Vantage：https://www.alphavantage.co

    - Tiingo：https://www.tiingo.com

    - Polygon.io：[https://massive\.com](https://massive.com/dashboard/)

## 3\. 各功能使用指引

顶栏功能按业务流程排列：**产业链分析 » 观察池 » 决策中心 «» 模拟交易 \| 系统配置中心**（管理员另有「用户管理中心」）。

**整体系统的基本使用流程是：**

#### **第一步** 从你给出的产业方向和最终产品角度出发，查找整个供应链系统里最瓶颈的环节在哪里？
#### **第二步** 找到这些关键的供应链环节里最重要的企业有哪些？
#### **第三步** 对这些企业进行多维度评分，主要目的是找到既重要（高质量分）又没有被市场充分发现（低alpha值）的“被低估企业”（高预期差）
#### **第四步**  为了避免幻觉，使用多AI模型对推荐企业进行交叉评审，已确定最终的推荐名单
#### **第五步**  用户将这些推荐企业可以加入到自己的“观察池”内由系统进行定期的跟踪分析
#### **第六步**  系统的决策中心会周期性的检查市场和目前观察池内股票的市场短期数据，并通过一系列决策流程形成一个模拟操作决议
#### **第七步**  AI决策中心会操作一个模拟账户实践自己的操作决议（分为美元账户和人民币账户）
#### **第八步**  系统会定期跟进真实市场的数据结算AI操作账户的盈亏情况，AI会根据反馈修正自己的市场策略和持仓策略，不断优化自己的判断模型，形成决策闭环。

### 3\.1 产业链分析（首页）

系统入口，用三步法从产业方向挖瓶颈供应商。三种用法：

- **快速赛道分析**：卡片上有预设赛道（GPU/AI 算力、人形机器人…）。

    - 点赛道按钮直接开始分析；

    - 点赛道上的 **⋯ 按钮** 打开「配置赛道参数」详细设置，可改 **市场 / 产业方向 / 终端产品 / 主分析模型**（每个赛道各自保存），再「开始分析」。

- **自定义分析**：自己输入终端产品/行业，自定义拆解深度等参数后运行。

- **热点扫描（⚡）**：自动检测当前市场热点行业，作为分析切入点。

产出：产业链逐层拆解 → 瓶颈环节评分（稀缺性/不可替代性/供需缺口/定价权/技术壁垒）→ 候选供应商 → 多模型交叉验证后的 Top 推荐。最后环节可将看中的标的企业**加入观察池**。

### 3\.2 观察池

你的自选股跟踪台。

- 股票分层（重点 focus / 普通 normal / 跟踪 track），可按市场（美股/A股）筛选。

- 系统会为观察池股票采集**行情、新闻、情报、财报、龙虎榜**等数据。

- 点某只股票打开**详情抽屉**，含多个页签：基本信息 / 价格 / 新闻 / 资金 / 情报 / 策略 / **深度分析\(UZI\)**。

    - 价格页签的 K 线支持 **日K / 周K / 月K / 年K** 切换（年K 可看十余年长周期），未加入观察池的企业也能查看真实走势。

    - 深度分析\(UZI\)：多维数据 \+ 估值建模 \+ 杀猪盘/风险检测，产出个股深度报告。

### 3\.3 决策中心

把观察池的个股信号，收敛成组合级、可执行的决策。决策中心可以在美股/A股市场之间切换，四层 \+ 投委会：

- **L1 宏观策略**：判断当前市场环境（regime/风险偏好/板块轮动）。

- **L2 组合策略**：目标仓位/板块配置/风控上限。

- **L3 战术计划**：个股级进出场计划。

- **L4 执行方案**：具体下单方案（数量/价格/方式），待你确认。

- **投委会**：多位 AI 委员从不同风格（风险/成长/价值/逆向）投票评审，可拦截高风险计划；支持用户质询。

- **催化剂**：跟踪影响标的的事件日历。

- **持仓风格**（右侧面板）：设定你的持仓偏好（集中/分散、换手快慢、最大单仓等），作为**硬约束**注入 L1–L4 各层，决策产出会遵守你的风格。

- **挂单交易**：批准的买/卖若未达目标价不再报错，而是自动按限价挂单等待——开市时**每小时撮合一次，最长 2 周到期自动取消**。展示区可看到挂单价/挂单时间/到期时间，也可随时手动取消。

页面片上有 **💬AI分析师** 按钮：点击后打开AI咨询抽屉式窗口，AI分析师会先列出本轮获取的市场/新闻数据，两位AI分析师（宏观市场 / 产业动向）自动流式解读，**你可实时提问，两人先各自作答再互评辩论**；你可以针对现在的宏观市场情况，观察池股票的整体分析，个股策略分析，模拟持仓分析等各类问题向AI分析师提问，你还可以上传各类宏观或者个股研报让分析师解读，如果Gangtise数据源打开，你也可以让分析师自行获取某企业研报。AI 给出的宏观指数点位/个股股价会**当场对系统权威数据核实**，若与真值不符会直接改成真值并标注「⚠系统核实」，避免 AI 口误误导。

AI对话按市场滚动保存，每日自动生成新的分析对话，可长期延续。

**决策中心运行方式：**可「日常决策」（轻量检查）或「全量刷新」（完整重跑 L1→L4）。页面另有「运行统计」面板，一眼看清从有记录以来累计跑了多少轮决策。
决策中心一旦开始运转之后，就会自动开始周期性的决策，用户只需要每天登录进入，查看决策中心L4待确认执行环节有无需要你确认执行的买入卖出操作，并批准同意或者驳回即可，这些操作会自动在模拟账户执行。

### 3\.4 模拟交易

这里是模拟交易的账户，这里是由决策中心那一大帮子AI操作的一个模拟纸面账户，用于验证决策中心产出的策略表现（**非真实交易**）。账户可以在美金账户/人民币账户之间切换（预设100万美金/500万人民币初始资金），账户盈亏会自动和真实市场对齐。

5 个页签：

- **账户盈亏**：总价值/收益率/胜率等 \+ **权益曲线**（可切 30/90/180/365 天）\+ 月度绩效/标的分布。

- **当前持仓**：持仓明细、成本、盈亏、占比；可展开单只的历史。

- **历史交易**：成交流水，可按 Ticker/方向筛选。

- **复盘记录**：交易复盘、AI自动生成经验卡片、交易反馈历史；可批量复盘。

- **账户操作**：存取资金、刷新市场价格、生成调优建议。

决策中心 L4 生成的执行计划，经你在待确认区确认后，会在模拟盘落地成交。

模拟账户的盈亏信息会周期性的回馈到决策中心进行复盘研究，用于调整和改进决策模型。

### 3\.5 系统配置中心

见第 2 节——API Key、模型使用策略、自动测试并配置、模型自定义分配、🧭 调度看板都在这里。
这里还有数据自动更新的设置（含桌面借道），用来设置你的各项外部信息的更新周期；也可配置**手机推送**（bark / Server酱 / 飞书），决策/待确认等关键事件会推到你手机。

### 3\.7 VIP 私人顾问（仅管理员）

## 5\. 常见问题排查

|现象|原因 \& 解决|
|---|---|
|分析提示「**无可用 LLM**」|没有可用的模型 Key。到系统配置中心「API KEY 管理」配好至少一个服务商的 Key + 默认模型，点一次「🚀 模型自动测试并配置」即可（调度器会自动为各角色选型）。|
|**图表 / 权益曲线加载失败**|前端图表库加载失败。本项目已把 echarts/d3/marked 本地化到 `static/vendor/`（国内 jsdelivr 等公共 CDN 不可达）。若你新增了公共 CDN 脚本会重现此问题——请改用本地 vendor。|
|注册收不到**验证码**|未配置 SMTP 时验证码打印在**服务器日志**里，直接从日志取。要发真实邮件请在 \.env 配 `SMTP_*`。|
|找不到 admin **密码**|首次启动的随机密码只在服务器日志打印一次，搜日志「已创建默认管理员」。丢了可在无用户环境重新初始化，或用管理员工具重置。|
|页面各处宽度/图表异常|改动 CSS/前端后请**硬刷新**浏览器（Ctrl\+Shift\+R）清缓存。|
|A 股数据|A 股行情/龙虎榜等依赖 AKShare，美股依赖 yfinance，需要网络可达对应数据源。|

## 6\. 数据与隐私

- 数据，按用户隔离，各用户只见自己的数据。

- **模拟交易是纸面盘，不产生任何真实下单**。

- 系统输出为 AI 辅助分析，**不构成投资建议**，据此决策风险自负。
