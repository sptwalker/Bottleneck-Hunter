系统总览：它到底能帮你做什么

BottleneckHunter 有三个各自独立又能打通的形态。你可以只用其中一个，也可以让它们连成一条从「选股」到「跟踪决策」再到「管理自己真实账户」的闭环。

图 1 · 三大形态：选股分析流程 → 决策中心 → VIP 私人顾问，可独立使用亦可打通

⚖ 贯穿全系统的一条底线：诚实，止于建议

  • 所有 AI 生成的分数、排名、建议都是研究参考，不构成投资建议，系统绝不自动下单、不碰真实资金。
  • 数据不足时诚实留空或降级（标注「样本不足 / 未核到 / 基于 N 期结单·非逐日」），绝不用一两个点冒充统计量、绝不编造数字。
  • AI 报告里每个金额/占比/股数都会与真实入库数据逐一核对，没核到当场标「⚠ 未核到」。

VIP 私人投资参谋

这是给你自己真实券商账户配的一位「周期性投资参谋」。你把券商月结单/交易流水导进来，它把散落在多家券商、多币种、多产品（股票+累购累沽+FCN 结构性产品）的账本汇成一屏，算清真实收益与风险，再基于你的产业链瓶颈布局给出加/减/持/对冲建议——只出建议、绝不下单。

图 2 · VIP 顾问五段管道：导入 → 重估 → 度量 → 研判 → 建议
一、导入与入库 把散落多家券商的账本统一收进来
结单导入

多券商结单统一入库

花旗、招银国际(CMBI)、野村三家券商的月/日结单，用各自专属解析器抽出持仓、现金、交易、结构性产品，统一落到一套规范账本。招银的 FCN、巴克莱的 FCN 条款单也能识别入库。

覆盖边界：目前内置花旗/招银/野村三家结单解析器；其他券商可走通用表格(CSV/Excel)导入。
流水导入

CSV / Excel 交易流水导入

不是这三家券商，或想补录历史成交？直接上传 CSV/Excel 交易表，系统按列名智能识别买卖/分红/费用/转账，并入同一账本。

隐私安全

加密结单密码解锁

券商 PDF 常带密码。导入时输入一次即可解密读取，密码绝不落库、绝不写进任何日志，用完即弃。

隐私承诺：密码是你的凭证，系统只读、只用于本次解密。
幂等

重复导入去重 + 字段回填

同一份结单重复导入不会产生重复记录（按内容指纹识别）；重新导入更完整的版本时，会把缺失字段回填、以最新解析为权威。

多账户

多账户自动归户

你在同一券商有多个子账户？系统按结单里的账户号自动归户，各账户独立统计、互不串味。

体检

缺数据体检报告

哪些标的没有活跃价源（市值还是结单结转价、非最新行情）、哪些币种缺汇率锚、哪些成本缺失——一份体检清单如实告诉你，不让你误以为数字都是最新的。

二、账户重估 每天按收盘价把账户估值刷新一遍
重估

持仓每日重估（统一美元口径）

多币种持仓一律折算到统一美元口径再算占比与总权益，避免港币/日元量级混淆。每个交易日按收盘价把账户重估一遍，形成一条净值曲线。

诚实口径：逐日推算基于「上一份权威结单 + 每日收盘价」，非券商逐日流水；结单到账即以结单为准校准。
护栏

防误覆盖护栏

解析异常或结单过期时，系统拒绝用坏数据覆盖已有的正确持仓——宁可提示「需人工复核」，也不静默写脏。

校准

推算校准

新结单一到账，就拿它和这段时间的每日推算对账；偏差超阈值（15%）会打旗提示，让推算始终贴近真实。

收益盈亏

未实现盈亏 · 成本结转 · 红负绿正

逐仓显示未实现盈亏，正收益绿色、负亏损红色。当最新快照是「仓盘导出」这类无成本列的薄快照时，会自动结转最近一期带成本结单的成本基，用当前市值重算盈亏——不会因为换了张结单就把收益清零。

诚实护栏：仅当持仓股数未变动才结转成本；买卖过或从无成本记录的标的，诚实留空不臆造。
三、真实业绩度量 剔掉你自己的转入转出，算出真业绩
收益率

真实收益率（Modified Dietz / MWR）

账户涨了不等于你赚了——你中途转入的钱会虚增账面。系统用 Modified Dietz / 资金加权法剔除你的注资与提取，算出真正归功于投资的收益率。

口径披露：需权威净值（含现金）口径才呈现精确收益率；仅持仓市值时如实标注「非权威口径」、不硬算。
风险

风险指标（Sharpe / Sortino / Calmar / 最大回撤）

不只看赚多少，还看承担了多大波动与回撤。给出夏普/索提诺/卡玛比率与最大回撤（无风险利率按 4% 年化）。

样本护栏：结单期数少于 3 期时诚实降级为空——绝不用两三个点冒充统计量。
归因

标的贡献归因

这段时间是谁在赚、谁在拖后腿？按相邻两期期初权重 × 单价收益拆解，列出贡献 Top / Bottom 榜。

已实现

FIFO 已实现盈亏

按先进先出配对买卖，算出真正落袋的已实现盈亏。

完整性闸门：流水残缺或非美元标的绝不冒充美元合计——残缺就留空，不硬凑一个假数字。
四、产业前瞻与衍生品 把你的产业链瓶颈观点接到真实账户上
主题

瓶颈主题暴露

把你账户里的持仓按产业链瓶颈环节归类，画出「哪些卡脖子主题超配、哪些低配」的定性主题图，接进投委会研判。

定性图：基于观察池已有的瓶颈节点归类，是方向性主题图，非量化强度暴露（如实标注）。
纲领

投资纲领对账

你可以设定自己的投资纲领（风险偏好/集中度上限/聚焦方向/排除清单）。系统逐条对账：单一持仓/前五大是否超限（保守 15/30 · 均衡 20/40 · 激进 30/50）。

轮动

行业轮动对账

把当前板块配置与宏观轮动桶对照，提示哪些行业相对宏观判断是超配或欠配。

衍生品

衍生品 KO/KI 监控

累购/累沽/FCN 这类结构性产品，逐日盯敲出(KO)/敲入(KI)价位，临近关键价位时提示。

压测

组合压力测试

模拟市场下跌 -10%/-20% 等情景下的组合盈亏。累购跌破 AFP「加倍套牢」的尾部损失如实呈现为更大亏损，不会被算法反转成收益。

覆盖披露：无到期模型的产品（如 FCN）诚实标未建模、剔出压测，不用公式臆造。
Greeks

组合净 Greeks

对可重放定价的衍生品做净 delta / gamma 聚合，看组合整体的方向性与凸性敞口。非美元腿、缺价标的诚实剔出并披露。

五、研判与建议 四位 AI 委员会审，逐仓给出可执行建议
投委会

投委会四人评审

复用决策中心的投委会机制，风控/成长/价值/逆向四位 AI 委员各自独立审视你的账户，多角度拷问、给出评审意见。

行动

逐仓行动计划 + 现金预算

不是一句空话，而是逐个持仓给出加/减/持/对冲的具体方向、理由，并结合可用现金给出预算约束。

死线：止于建议层——只给方向与理由，绝不下单、不承诺收益。
荐新

荐新标的

结合你的瓶颈布局与纲领，从研究侧推荐值得关注的新标的作为候选。

对话

实时咨询对话

随时就账户里的任何问题追问 AI 顾问，流式实时回答，像和一位私人参谋聊天。

六、可信与合规保障 让每个数字都可核对、每条建议都有边界
防幻觉

AI 数字幻觉防护

AI 报告里出现的每个金额/占比/股数，都会与真实入库数据逐一核对（1% 容差），没核到的当场标「⚠ 未核到」，杜绝 AI 编数字。

合规

合规免责声明

所有输出附带版本化合规免责声明，明确「研究参考、非投资建议」。

锁屏

VIP 密码锁屏

VIP 区独立密码锁，未解锁一律拦截（423）——你的真实账本多一道门。

隔离

管理员专属 + 严格隔离

VIP 顾问为单一管理员专用，数据严格按用户隔离；决策中心的模拟盘与 VIP 真实账本彻底解耦、互不污染。

选股分析流程 · 产业链瓶颈三步法

找股票不从热门名字开始，而从「哪个环节卡脖子」开始。三步法：先把终端产品逐层拆到原材料，找出供给最紧、最不可替代的瓶颈环节；再沿瓶颈找被忽视的优质供应商；最后让多个 AI 从反面拷问投资逻辑，只有扛得住质疑的才留下。

1

产业链拆解

从终端产品逐层拆到原材料，3-5 层深度，画出完整产业链树。

2

瓶颈 + 供应商

五维给每个环节评瓶颈分，沿最卡环节检索被低估的优质供应商。

3

交叉验证

多个 AI 模型从反面拷问，圆桌辩论，只留扛得住质疑的标的。

拆解

AI 产业链拆解

输入一个终端产品，AI 自动逐层拆解到上游原材料（3-5 层），生成结构化产业链树。

评分

瓶颈五维评分

对每个环节按稀缺性/不可替代性/供需缺口/定价权/技术壁垒五维打分，并按行业调权，定位真正的卡脖子点。

集中度

真实集中度 CR3/CR5/HHI

A 股环节用东财真实数据算行业集中度（CR3/CR5/HHI），佐证瓶颈判断，不靠 AI 空谈。

覆盖边界：真实集中度目前覆盖 A 股；美股环节以定性判断为主。
检索

供应商检索 + 行情验证

沿瓶颈环节检索供应商，再用四道硬规则过滤（市值≥15亿/毛利≥20%/日成交额/上市满 365 天），剔掉不可投的壳与仙股。

评估

供应商五维评估 + 预期差

对候选供应商做五维基本面评估，并给「预期差 Alpha」评分——市场还没充分定价的机会才有超额收益。

验证

多模型交叉验证

四个视角、多个 LLM 独立拷问投资逻辑，命中致命风险直接压分，只精验 Top 10，把资源花在最有希望的标的上。

辩论

AI 投研圆桌辩论

四个角色 AI 圆桌辩论，用 Borda 计数法综合排序，模拟一场真实的投研会。

催化剂

催化剂时间线

为标的梳理未来 6-18 个月可能的股价催化剂事件时间线。

热点

全市场热点板块扫描

A 股按板块聚合扫描当下热点，快速定位资金关注方向。

覆盖边界：热点扫描目前聚焦 A 股板块。
报告

Markdown 报告 + CLI 向导

全流程产出结构化 Markdown 报告；命令行向导带你一步步走完选股，用户数据隔离。

🧭

决策中心 · 四层决策 + 投委会 + 模拟交易

选出来的股票不是就完了，而是放进观察池持续跟踪。系统按四层决策把「宏观怎么看 → 组合怎么配 → 战术怎么打 → 具体怎么执行」串成一条链，投委会评审后进模拟盘验证，再自动复盘沉淀经验——一个会自我进化的决策闭环。

图 3 · L1→L4 四层决策链，逐层收敛到可执行动作
观察池

分档跟踪观察池

候选标的按重要度分档进观察池，各档跟踪频率与深度不同，把注意力花在刀刃上。

L1

L1 宏观决策

判断大势与板块轮动，给出「该不该重仓、偏向哪些方向」的宏观基调与轮动桶。

L2

L2 组合决策

在宏观基调下定目标配置与各标的权重，并对目标配置做上下限夹逼。

L3

L3 战术决策

给出买卖时机与价格区间，把组合意图落到具体的分批动作。

L4

L4 执行 + 硬约束闸门

最后一道关：硬约束闸门自动检查，越界先让 LLM 自修正两次，仍越界则缩量或直接拦截，绝不放行违规动作。

投委会

投委会评审 + 质询改票

四位 AI 委员（各挂不同模型）独立评审，可互相质询、改票，模拟真实投委会的对抗式决策。

风格

个人持仓风格硬约束

你的持仓风格（激进/均衡/保守等）作为硬约束注入每一层，单一持仓上限等做硬校验，决策始终贴合你的偏好。

模拟盘

模拟交易闭环

决策确认后进虚拟盘执行（含 0.1% 佣金），限价挂单 + 滑点模拟、挂单 14 天，完整走一遍真实交易流程——不碰真钱。

复盘

自动复盘经验卡 + 偏好学习

每笔交易自动复盘，沉淀成经验卡；六维度偏好学习让系统越用越懂你。

调度

双市场定时调度

A 股 / 美股按各自交易时段定时跑决策，漏跑自动补跑（misfire 补偿），不会因宕机丢一天。

催化剂

催化剂监控

持续监控观察池标的的催化剂事件，触发时提示复核。

风控

风控仪表盘

组合集中度(HHI)、单板块占比、相关性、VaR/CVaR/beta 一屏看清，越线预警。

追溯

决策全链路 Trace

每个决策从宏观到执行的完整推理链可追溯，随时回看「当时为什么这么决定」。

🔌

系统拓展能力

系统的「能力上限」不是写死的。AI 模型、数据源、用户，都是即插即用、按用户隔离的——换更强的模型、加新数据源、多人各用各的 Key，都不用改核心代码。

多模型

多 AI 模型即插即用

内置 11+ 家 AI provider（openai/anthropic/deepseek/google/qwen/glm/kimi/minimax/硅基流动/openrouter 等），随时切换、随时加新模型，核心逻辑不动。

自助配置

AI 配置中心自助 + 测试

顶栏一个统一入口，自己填 Key、测连通、按角色分配模型——不用找管理员，也不用改配置文件。

自定义

自定义 provider 目录

管理员可建 provider 目录，每个用户填自己的 Key，Key 严格隔离——绝不共用、绝无全局 Key。

智能调度

模型智能调度

不是静态分配，而是数据驱动地为每个任务挑最合适的模型（主模型优先 → DB 角色矩阵 → 角色默认 → 健康度排序），遥测越多越准。

熔断

失效自动熔断 + 无感切换

某个模型认证失败/限流/超时，自动熔断并无感切到备节点，不重复等挂死节点、不丢已产出内容。主模型失效会自动取消并提示你重选。

数据源

多市场数据源 failover

行情/财务/新闻/期权跨 8 家数据源（FMP/Finnhub/Tushare/Akshare/AlphaVantage/Tiingo/Polygon 等），一家不可用自动换下一家。

隔离

多用户级严格隔离

Key 用 AES-256-GCM 加密存储，邀请码注册，每个用户的 Key/配置/熔断状态绝对隔离，一个用户的失败绝不波及他人。

选型

按角色容量事前选型 + 容错

不同角色需要的上下文容量不同，系统事前按容量选型，容量不够自动 fallback，避免「塞不下」的静默失败。

离线

前端库全本地化

所有前端库（echarts/d3/marked 等）本地打包，零外部 CDN 依赖——国内网络也能稳定打开，本说明书本身就是如此。

🚀

未来可扩展的功能模块

系统按「先证明价值、再加复杂度」的原则演进。下面如实标注每个方向的状态——已建成、已规划、守门待证明（价值未在生产验证前刻意不建）、明确不建（越界或不必要）。不画不打算兑现的大饼。

已建成

可信后视镜（Phase 0-4 全线）

真实收益率/风险指标/贡献归因、FIFO 已实现盈亏、瓶颈主题暴露、投资纲领对账、衍生品逐日监控、组合压力测试与净 Greeks——从「导入结单」到「组合级尾部风险」的完整可信账户回望，已全部建成并通过验收。

已规划

诚实边界 · 这个系统的底线

很多系统的问题不是不能算，而是「没数据也硬算、算错了不说」。这个系统把诚实做成了硬约束——下面每一条都是代码级的红线。

⚖ 七条不可逾越的红线

  • 止于建议：只给加/减/持/对冲方向与理由，绝不自动下单、不碰真实资金。
  • 数据不足就留空：结单期数少于 3 期不算风险统计量，非权威口径不呈现精确收益率——诚实降级，不冒充。
  • 衍生品单列：结构性产品名义敞口单独列示，绝不并入权益头条虚增总资产；非美元不混美元口径。
  • 已实现盈亏诚实：流水残缺就留空，不用 FIFO 硬凑一个假的已实现盈亏。
  • 尾部风险不反转：累购跌破 AFP「加倍套牢」的巨亏如实呈现为更大亏损，不被算法符号反转成收益。
  • 覆盖口径必披露：哪些标的有价、哪些缺价缺锚、哪些成本靠结转——全部如实标注。
  • 数字必核对：AI 报告里每个数字与真实入库数据逐一核对，没核到当场标「⚠ 未核到」。
