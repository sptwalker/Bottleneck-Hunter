# 估值分析_OpenAPI 接口文档

## 一、接口描述

**功能概览**：本接口用于获取 **Gangtise** 金融市场个股估值指标的历史时间序列数据，涵盖市盈率、市净率、市销率等多维估值维度，并提供分位点、均值、标准差等统计分析字段。

**典型应用场景**：

* 适用于投研系统集成、个股估值监控或量化选股模型，帮助专业投资者从历史维度评估当前估值水平的高低。

**使用方法**：

* **指定证券与指标**
  通过 `securityCode` 指定目标股票，通过 `indicator` 选择所需估值指标（如 `peTtm`、`pbMrq` 等）。
* **时间区间筛选**
  通过 `startDate` 与 `endDate` 指定查询区间，格式严格遵循 `yyyy-MM-dd`；若不传则默认返回结束日期往前一年的数据。
* **按需返回字段**
  通过 `fieldList` 指定需要的返回字段（如 `value`、`percentileRank`、`median` 等），不指定则返回全部字段。
* **分批拉取**
  单次最大返回 `2000` 行，系统上限为 `10000` 行；如需更长区间数据，请缩短日期范围分批请求。

<br/>

## 二、数据权限范围

* **数据权限长度**：
  * **试用账号**：当前时间前溯 **3 年**的历史存量数据。
  * **正式账号**：数据权限为当前时间前溯 **5 年** 的历史存量数据。

<br/>

## 三、OpenAPI 积分消耗

**无积分消耗**

<br/>

## 四、请求说明

### 请求地址

* `https://openapi.gangtise.com/application/open-fundamental/valuation-analysis`

### 请求方式

* **POST**

### 请求头
| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `Authorization` | **String** | accessToken，从<a href="#/markdown/access-token">【accessToken】</a> 接口获取 |

<br/>

## 五、请求参数

| 参数名 | 必选 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `securityCode` | 是 | **String** | - | 股票代码，格式如：`"600519.SH"` |
| `indicator` | 是 | **String** | - | 估值指标，支持：<br>• `peTtm` - 滚动市盈率<br>• `pbMrq` - 市净率<br>• `peg` - 市盈率相对盈利增长比率<br>• `psTtm` - 滚动市销率<br>• `pcfTtm` - 滚动市现率<br>• `em` - 企业倍数 |
| `startDate` | 否 | **String** | 结束日期一年前 | 开始日期，格式严格为 `yyyy-MM-dd` |
| `endDate` | 否 | **String** | 当前日期 | 结束日期，格式严格为 `yyyy-MM-dd` |
| `limit` | 否 | **Integer** | 2000 | 单次请求最大返回行数（系统最高上限为 `10000` 行，超过该限制请缩短日期区间分批拉取） |
| `fieldList` | 否 | **List\<String\>** | - | 从返回参数中指定返回的字段，不指定则返回全部 |

### 请求示例（JSON）

```json
{
  "securityCode": "600519.SH",
  "indicator": "peTtm",
  "startDate": "2024-01-25",
  "endDate": "2024-02-23",
  "limit": 2000,
  "fieldList": [
    "value",
    "percentileRank",
    "average"
  ]
}
```

<br/>

## 六、返回参数

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `indicator` | **String** | 估值指标名称（如：`"peTtm"`） |
| `fieldList` | **List\<String\>** | **列名表头**。严格与请求的 `fieldList` 顺序一致，定义了下方 `list` 中每个数据组的含义 |
| `tradeDate` | **String** | 交易日期，格式为 `yyyy-MM-dd`（固定字段） |
| `value` | **Double** | 原始值 |
| `percentileRank` | **Double** | 分位点（基于所选时间区间内的数据计算） |
| `average` | **Double** | 平均值（基于所选时间区间内的数据计算） |
| `median` | **Double** | 中位数（基于所选时间区间内的数据计算） |
| `upper1Std` | **Double** | +1 标准差（基于所选时间区间内的数据计算） |
| `lower1Std` | **Double** | -1 标准差（基于所选时间区间内的数据计算） |
