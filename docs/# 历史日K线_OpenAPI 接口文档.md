# 历史日K线_OpenAPI 接口文档

## 一、接口描述

**功能概览**：本接口用于获取 **Gangtise** 金融市场的历史日K线数据，支持 **A 股、港股、美股** 三大市场个股，同时支持 **交易所指数（沪深京）、概念指数、行业指数（中信/申万一二三级）**，包含开盘价、最高价、最低价、收盘价、昨收价、涨跌额、涨跌幅、成交量、成交额及复权因子等字段。**本接口仅提供历史日K线数据，不提供实时行情。**

**支持个股市场及代码格式**：

| 市场 | 交易所 | 代码格式示例 |
| :--- | :--- | :--- |
| **A 股** | 上交所 / 深交所 / 北交所 | `600519.SH`、`000858.SZ`、`835305.BJ` |
| **港股** | 香港交易所 | `00700.HK` |
| **美股** | NYSE / NASDAQ / AMEX | `AAPL.O`、`MSFT.O` |

**支持指数类型及代码格式**：

| 指数类型 | 代码后缀 | 说明 | 代码格式示例 |
| :--- | :--- | :--- | :--- |
| **交易所指数** | `.SH` / `.SZ` / `.BJ` | 沪深京交易所官方指数（如上证指数、深证成指、创业板指、科创50、北证50 等） | `000001.SH`（上证指数）、`399001.SZ`（深证成指）、`399006.SZ`（创业板指） |
| **概念指数** | `.GT` | 概念/题材类指数（如机器人、人工智能、固态电池等） | `880134.GT`（机器人） |
| **行业指数（中信）** | `.CI` | 中信行业分类指数，覆盖一级、二级、三级行业 | `821021.CI`（中信银行） |
| **行业指数（申万）** | `.SWI` | 申万行业分类指数，覆盖一级、二级、三级行业 | `821031.SWI`（申万农林牧渔） |

> **价格/金额字段货币单位说明**：
> - **A 股**：元（CNY）
> - **港股**：港元（HKD）
> - **美股**：美元（USD）
> - **指数**：指数点位，无货币单位

**典型应用场景**：

* 适用于量化策略回测、技术分析指标计算、行情可视化展示等场景，帮助专业投资者进行历史行情数据分析。

**使用方法**：

- **按证券筛选**
  通过 `securityList` 参数指定证券代码列表，支持 A 股、港股、美股、交易所指数、概念指数、行业指数混合传入（如 `["600519.SH", "00700.HK", "000001.SH"]`）。不同市场的证券各自返回其所属交易所的交易日数据，A 股仅返回沪深京交易日、港股仅返回港交所交易日、美股仅返回纽交所/纳斯达克交易日。例如春节期间 A 股休市而美股正常交易时，返回结果中当期仅含美股数据行而无 A 股数据；反之美国独立日等美股假日，若 A 股为交易日则有 A 股数据而无美股数据。
- **按市场批量查询**
  通过 `securityList` 传入市场标识，支持以下三种：
  - `["aShares"]` — 返回全部 A 股数据
  - `["hkStocks"]` — 返回全部港股数据
  - `["usStocks"]` — 返回全部美股数据

  > **注意**：市场标识（`aShares` / `hkStocks` / `usStocks`）仅允许**单独传入**，数组中只能填一个板块标识，不可与其他板块标识或股票代码混填。如 `["aShares", "600519.SH"]` 或 `["aShares", "hkStocks"]` 均为非法请求。
* **按日期查询**
  通过 `startDate` 与 `endDate` 参数过滤日期区间，格式严格为 `yyyy-MM-dd`。
* **指定返回字段**
  通过 `fieldList` 参数指定需要返回的字段，不指定则返回全部字段。

<br/>

## 二、数据权限范围

* **试用账号**与**正式账号**均支持查询全市场历史日K线数据，数据范围覆盖 A 股、港股、美股、交易所指数、概念指数及行业指数。
* **数据权限长度**：
  * **试用账号**：当前时间前溯 **3 年**的历史存量数据。
  * **正式账号**：当前时间前溯 **5 年**的历史存量数据。
* **数据入库时间**：交易日当日数据一般在 **15:30 左右**完成入库，入库后方可查询。

## 四、请求说明

### 请求地址

* `https://openapi.gangtise.com/application/open-quote/kline/daily`

### 请求方式

* **POST**

### 请求头
| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `Authorization` | **String** | accessToken，从<a href="#/markdown/access-token">【accessToken】</a> 接口获取  |

<br/>

## 五、请求参数

| 参数名 | 必选 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `securityList` | 是 | **List\<String\>** | - | • 证券代码列表，支持 A 股、港股、美股、交易所指数、概念指数、行业指数混合传入（如 `["600519.SH", "00700.HK", "000001.SH"]`）<br>• 传入 `["aShares"]` 返回全部 A 股<br>• 传入 `["hkStocks"]` 返回全部港股<br>• 传入 `["usStocks"]` 返回全部美股<br>• 指数不支持全市场批量查询，须传入具体的 GTS Code<br><br>**⚠️ 约束**：市场标识（`aShares` / `hkStocks` / `usStocks`）仅允许单独传入，数组中只能填一个板块标识，不可与股票代码或其他板块标识混填。 |
| `startDate` | 否 | **String** | endDate往前一年 | 开始日期，格式严格为 `yyyy-MM-dd` |
| `endDate` | 否 | **String** | 最新已入库交易日 | 结束日期，格式严格为 `yyyy-MM-dd` |
| `limit` | 否 | **Integer** | 6000 | 单次请求最大返回行数（系统最高上限为 10000 行，超过该限制请缩短日期区间分批拉取） |
| `fieldList` | 否 | **List\<String\>** | - | 从返回参数中指定返回的字段，不指定返回全部 |

### 请求示例（JSON）

**示例 1：按证券代码查询**

```json
{
  "securityList": [
    "600519.SH",
    "000858.SZ"
  ],
  "startDate": "2024-05-01",
  "endDate": "2024-05-20",
  "limit": 5000,
  "fieldList": [
    "securityCode",
    "tradeDate",
    "open",
    "close",
    "volume",
    "adjustFactor"
  ]
}
```

**示例 2：混合查询个股与指数**

```json
{
  "securityList": [
    "00700.HK",
    "000001.SH",
    "880134.GT",
    "821031.SWI"
  ],
  "startDate": "2024-05-01",
  "endDate": "2024-05-20",
  "limit": 5000,
  "fieldList": [
    "securityCode",
    "tradeDate",
    "open",
    "close",
    "pctChange",
    "volume",
    "amount"
  ]
}
```

## 六、返回参数

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `fieldList` | **List\<String\>** | **列名表头**。严格与请求的 `fieldList` 顺序一致，定义了下方 `list` 中每个数据组的含义 |
| `securityCode` | **String** | 证券代码（如个股：`"600519.SH"`、`"00700.HK"`；指数：`"000001.SH"`、`"880134.GT"`、`"821031.SWI"`） |
| `tradeDate` | **String** | 交易日期，格式为 `yyyy-MM-dd` |
| `open` | **Double** | 开盘价（A 股：元 / 港股：港元 / 美股：美元；指数为开盘点位） |
| `high` | **Double** | 最高价（A 股：元 / 港股：港元 / 美股：美元；指数为最高点位） |
| `low` | **Double** | 最低价（A 股：元 / 港股：港元 / 美股：美元；指数为最低点位） |
| `close` | **Double** | 收盘价（A 股：元 / 港股：港元 / 美股：美元；指数为收盘点位） |
| `preClose` | **Double** | 昨收价（A 股：元 / 港股：港元 / 美股：美元；指数为昨收点位） |
| `change` | **Double** | 涨跌额 |
| `pctChange` | **Double** | 涨跌幅（%） |
| `volume` | **Long** | 成交量（单位：股） |
| `amount` | **Double** | 成交总额（A 股：元 / 港股：港元 / 美股：美元；指数：元） |
| `adjustFactor` | **Double** | **复权因子**。反映该证券自上市以来的除权除息累积效应。<br>• 后复权价格：$$P_{backward}(t) = P_{unadjusted}(t) \times F_{adj}(t)$$<br>• 前复权价格（最新价作为基准日）：$$P_{forward}(t) = P_{unadjusted}(t) \times \frac{F_{adj}(t)}{F_{adj}(T_{latest})}$$<br>• 指数不含复权因子，该字段为 null |
