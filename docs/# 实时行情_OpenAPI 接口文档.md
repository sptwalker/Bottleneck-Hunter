# 实时行情_OpenAPI 接口文档

## 一、接口描述

**功能概览**：本接口用于获取 **Gangtise** 金融市场的实时行情快照数据，支持 **A 股、港股、美股** 三大市场个股，同时支持 **交易所指数（沪深京）、概念指数、行业指数（中信/申万一二三级）**，包含最新价、开盘价、最高价、最低价、昨收价、涨跌额、涨跌幅、成交量、成交额、振幅等字段。**本接口返回最新时刻的行情快照，适用于盘中实时监控场景。**

**支持个股市场及代码格式**：

| 市场 | 交易所 | 代码格式示例 |
| :--- | :--- | :--- |
| **A 股** | 上交所 / 深交所 / 北交所 | `600519.SH`、`000858.SZ`、`835305.BJ` |
| **港股** | 香港交易所 | `00700.HK` |
| **美股** | NYSE / NASDAQ / AMEX | `AAPL.O`、`MSFT.O` |

**支持指数类型及代码格式**：

| 指数类型 | 代码后缀 | 说明 | 代码格式示例 |
| :--- | :--- | :--- | :--- |
| **交易所指数** | `.SH` / `.SZ` / `.BJ` | 沪深京交易所官方指数（如上证指数、深证成指、创业板指、科创50、北证50 等） | `000001.SH`（上证指数）、`399001.SZ`（深证成指）、`399006.SZ`（创业板指） |
| **概念指数** | `.GT` | 概念/题材类指数（如机器人、人工智能、固态电池等） | `880134.GT`（机器人） |
| **行业指数（中信）** | `.CI` | 中信行业分类指数，覆盖一级、二级、三级行业 | `821021.CI`（中信银行） |
| **行业指数（申万）** | `.SWI` | 申万行业分类指数，覆盖一级、二级、三级行业 | `821031.SWI`（申万农林牧渔） |

> **价格/金额字段货币单位说明**：
> - **A 股**：元（CNY）
> - **港股**：港元（HKD）
> - **美股**：美元（USD）
> - **指数**：指数点位，无货币单位

**典型应用场景**：

* 适用于盘中实时监控、量化交易信号触发、行情大屏展示、自选股盯盘、指数走势跟踪等场景，帮助专业投资者获取最新市场动态。

**使用方法**：

- **按证券筛选**
  通过 `securityList` 参数指定证券代码列表，支持 A 股、港股、美股、交易所指数、概念指数、行业指数混合传入（如 `["600519.SH", "00700.HK", "000001.SH", "880134.GT", "821021.CI"]`）。
- **按市场批量查询**
  通过 `securityList` 传入市场标识，支持以下三种：
  - `["aShares"]` — 返回全部 A 股数据
  - `["hkStocks"]` — 返回全部港股数据
  - `["usStocks"]` — 返回全部美股数据

  > **注意**：市场标识（`aShares` / `hkStocks` / `usStocks`）仅允许**单独传入**，数组中只能填一个板块标识，不可与其他板块标识或股票代码混填。如 `["aShares", "600519.SH"]` 或 `["aShares", "hkStocks"]` 均为非法请求。
* **指定返回字段**
  通过 `fieldList` 参数指定需要返回的字段，不指定则返回全部字段。

* `https://openapi.gangtise.com/application/open-quote/quote/realtime`

### 请求方式

* **POST**

| :--- | :--- | :--- |

## 五、请求参数

| 参数名 | 必选 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `securityList` | 是 | **List\<String\>** | - | • 证券代码列表，支持 A 股、港股、美股、交易所指数、概念指数、行业指数混合传入（如 `["600519.SH", "00700.HK", "000001.SH", "880134.GT", "821021.CI"]`）<br>• 传入 `["aShares"]` 返回全部 A 股<br>• 传入 `["hkStocks"]` 返回全部港股<br>• 传入 `["usStocks"]` 返回全部美股<br>• 指数不支持全市场批量查询，须传入具体的 GTS Code<br><br>**⚠️ 约束**：市场标识（`aShares` / `hkStocks` / `usStocks`）仅允许单独传入，数组中只能填一个板块标识，不可与股票代码或其他板块标识混填。 |
| `fieldList` | 否 | **List\<String\>** | - | 从返回参数中指定返回的字段，不指定返回全部 |

## 六、返回参数

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `fieldList` | **List\<String\>** | **列名表头**。严格与请求的 `fieldList` 顺序一致，定义了下方 `list` 中每个数据组的含义 |
| `securityCode` | **String** | 证券代码（如个股：`"600519.SH"`、`"00700.HK"`、`"AAPL.O"`） |
| `exchange` | **String** | 交易所/指数类型代码：`SH`（上交所）、`SZ`（深交所）、`BJ`（北交所）、`HK`（港交所）、`NYSE`（纽约证券交易所）、`NASDAQ`（纳斯达克）、`AMEX`（美国证券交易所）、`SH`/`SZ`/`BJ`（交易所指数）、`GT`（概念指数）、`CI`（中信行业指数）、`SWI`（申万行业指数） |
| `tradeDate` | **String** | 交易日期，格式为 `yyyy-MM-dd` |
| `tradeTime` | **String** | 最新行情时间，格式为 `HH:mm:ss` |
| `open` | **Double** | 开盘价 |
| `high` | **Double** | 最高价 |
| `low` | **Double** | 最低价 |
| `latestPrice` | **Double** | **最新价**（当前最新成交价） |
| `preClose` | **Double** | 昨收价 |
| `change` | **Double** | 涨跌额（最新价 - 昨收价） |
| `pctChange` | **Double** | 涨跌幅（%） |
| `volume` | **Long** | 成交量（单位：股，当日累计） |
| `amount` | **Double** | 成交总额（当日累计） |
| `amplitude` | **Double** | 振幅（%）= (当日最高价 - 当日最低价) / 昨收价 × 100% |

## 七、接口限制说明

* **全市场查询**：传入 `["aShares"]`、`["hkStocks"]` 或 `["usStocks"]` 查询全市场时，仅允许单独传入一个板块标识，不可混填股票代码或其他板块。返回数据量较大，建议使用 `fieldList` 精简返回字段以提升响应速度。
* **指数查询**：指数不支持全市场批量查询，须传入具体的 GTS Code 按需查询。
* **非交易时间**：非交易时间调用本接口，返回最近一个交易日的收盘行情快照。
* **停复牌**：停牌证券返回停牌前最后一个有效行情快照，字段可能为空或保持不变。
* **时区说明**：各市场交易时间对应的北京时间如下：
  * **A 股及交易所指数**：09:30 - 11:30、13:00 - 15:00
  * **港股**：09:30 - 12:00、13:00 - 16:00
  * **美股（夏令时）**：21:30 - 次日 04:00
  * **美股（冬令时）**：22:30 - 次日 05:00
  * **概念指数 / 行业指数**：与 A 股交易时间一致（09:30 - 15:00）
